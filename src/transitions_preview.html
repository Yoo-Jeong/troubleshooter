트랜지션

실제 모듈(assets/css/transitions.css · assets/js/transitions.js)을 그대로 재생합니다.
트랜지션을 수정한 뒤 이 페이지를 새로고침(F5)하면 바로 반영됩니다.
각 카드의 회색 코드박스 = 그 전환을 실제로 쓰는 방법(대개 링크에 data-ts 속성만 달면 적용).
우측 상단 ◐ 로 라이트·다크 두 테마 모두 확인할 수 있습니다.

※ '프로필' = 캐릭터 프로필 페이지.
  • accesslog 접속 로그 타이핑 → ACCESS GRANTED HOME → CHARACTERS · 목록 진입 <a href="…" data-ts="accesslog">

  • grant 조용한 페이드 + ● ACCESS GRANTED (스캔·타이핑 없이 깔끔한 접속 승인) CHARACTERS → 프로필 · 레코드 진입 (현재 적용) <a href="…" data-ts="grant">
  • scan 스캔 라인이 위→아래로 훑으며 화면을 라인 단위로 그려냄 (렌더 리빌) 라이브러리 · 아직 라우트 미배선 <a href="…" data-ts="scan">
  • resync 신호 재동기화 · 절제된 글리치 후 화면 전환 라이브러리 · 아직 라우트 미배선 <a href="…" data-ts="resync">
  • slide-left 실제 화면이 왼쪽으로 이동 · 새 화면이 오른쪽에서 들어옴 (가로 슬라이드) 라이브러리 · 아직 라우트 미배선 <a href="…" data-ts="slide-left">
  • slide-up 실제 화면이 위로 이동 · 새 화면이 아래에서 올라옴 (세로 슬라이드) 라이브러리 · 아직 라우트 미배선 <a href="…" data-ts="slide-up">
  • fade 조용한 페이드 복귀 전용 · 프로필→CHARACTERS · CHARACTERS→HOME <a href="…" data-ts="fade">
  • instant 즉시 컷 (애니메이션 없음) 모션 최소화 요청 시 폴백 <a href="…" data-ts="instant">
